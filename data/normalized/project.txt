[PROJECT-01] BENCHMARK ASSUMPTIONS: Three technical components: FAN, SENSOR, DRIVER. A conceptual ESP32 reads I2C temperature and commands DRIVER ON. Common ground; regulated 5 V fan rail and 3.3 V sensor/control rail. No PWM speed control. No hardware has been built or verified.
[PROJECT-02] Operating point for current/speed: 5 V fan terminals, 25 degrees C, vertical free air, after five minutes. These are declared test conditions; the load-switch drop and board design must be validated in a future prototype.
[PROJECT-03] CFG-THRESHOLD = 35 degrees C. CFG-SENSOR-SUPPLY = 3.3 V. Configuration values are project choices, not manufacturer specifications.
[PROJECT-04] Verification independence: current and speed tests force ON; the threshold test injects measured values at the software boundary and observes the command. Rail verification is separate. Do not propagate threshold or sensor-rail changes into force-ON current/speed tests. Only direct evidence invalidation within these stated tests is scored; no assumed thermal, aerodynamic or timing chains.
[PROJECT-05] Fan replacement invalidates current and speed evidence; switch replacement invalidates the documentary switch-rating evidence. Sensor supply changes invalidate sensor supply evidence. Cosmetic edits do not invalidate technical evidence. 'Affected' means review/reverification is needed, not that a requirement is necessarily violated.
